# Experiment 7 - Notes App (React.js)

A single-page application built with React.js that allows users to view, add, update, and delete notes.

## Files
- index.html - page structure and CDN links for React and Babel
- style.css - styling
- react.js - React components (NoteForm, NoteList, App)

## How to run
Open the folder in VS Code and use the Live Server extension, or host it with GitHub Pages.
